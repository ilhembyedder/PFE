# Soutenance PFE — supports

| Fichier | Quoi |
|---|---|
| [`presentation.html`](presentation.html) | Le support projeté : 24 slides au format 16/9, avec les notes d'orateur sous chaque slide |
| [`fiche-orateur.md`](fiche-orateur.md) | Minutage, script de passage, questions du jury et réponses, checklist du jour J |

## Projeter la présentation

Ouvrir `presentation.html` dans un navigateur. Les slides défilent verticalement et se redimensionnent à la largeur de la fenêtre ; les notes d'orateur apparaissent sous chaque slide, à l'écran uniquement.

Le fichier est autonome à une exception près : les polices (Source Serif 4 et IBM Plex Sans) sont chargées depuis Google Fonts. **Sans connexion, le navigateur bascule sur Georgia et Arial** — la mise en page tient, seul le rendu typographique change. Pour une projection hors ligne, exporter en PDF à l'avance.

## Exporter en PDF

Ouvrir `presentation.html`, puis imprimer (Ctrl+P) :

- Destination : **Enregistrer au format PDF**
- Marges : **Aucune**
- Cocher **Graphiques d'arrière-plan**

Chaque slide occupe une page ; les notes d'orateur sont exclues de l'impression.

Une version PowerPoint téléchargeable est également disponible depuis l'artefact en ligne, dont le lien figure dans la conversation d'origine.

## Avant de projeter

Deux points restent à traiter, détaillés dans la fiche orateur :

1. **Slide 1** — compléter les champs entre crochets : encadrant académique, encadrant professionnel, établissement.
2. **Écarts rapport / code** — sept écarts entre `RapportPFE.pdf` et le dépôt sont recensés dans la fiche, avec la réponse à tenir devant le jury.
